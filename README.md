# FilmVerse

Mở thư mục bằng VS Code và chạy `index.html` với Live Server.

Luồng chính: `index.html` → `products.html` → `product-detail.html?id=ID` → `cart.html` (watchlist).

Dữ liệu phim bộ từ [TVmaze](https://www.tvmaze.com/api), không cần API key. Trang chỉ cung cấp thông tin, không phát video. Có ghi nguồn TVmaze trên giao diện.

- Đọc `HUONG_DAN_BAT_DAU.txt` để lần theo code.
- Đọc `NOTE_REVIEW_CUA_THAY.txt` để xem phần đã sửa và bài tập tiếp theo.
- Các trang tên phim cũ chỉ còn để tham khảo bố cục.
- Tài khoản và watchlist lưu trong trình duyệt, chỉ dùng dữ liệu demo.
